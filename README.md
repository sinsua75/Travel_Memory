## 🎯 프로젝트 소개

**Travel Memory**는 "가고 싶은 여행지"와 "다녀온 여행지"를 한곳에 모아, 그 여행에 어울리는 **노래**와 함께 기록하는 웹 서비스입니다.

국가와 도시를 입력하면 대표 사진이 자동으로 붙고, 노래를 검색해 고르면 **30초 미리듣기**까지 카드에 저장됩니다.
저장한 여행은 홈 화면의 통계, 즐겨찾기, LP 화면에서 다시 꺼내 볼 수 있습니다.

> 여행의 기억은 풍경만이 아니라 **그때 들었던 노래**로도 남는다는 생각에서 출발했습니다.

## 💡 기획 의도

| 기존 여행 기록 서비스의 아쉬움 | Travel Memory의 해결 |
| --- | --- |
| 사진·메모 중심이라 **분위기와 감정**이 남지 않는다 | 여행마다 **노래를 함께 저장**하고 바로 들어볼 수 있다 |
| 가고 싶은 곳(버킷리스트)과 다녀온 곳이 따로 관리된다 | **예정 / 방문 완료** 상태를 한 목록에서 관리한다 |
| 기록하려면 사진을 직접 찾아 올려야 한다 | 국가·도시만 입력하면 **사진이 자동으로 검색**된다 |
| 다녀온 뒤 느낀 점을 남길 곳이 없다 | 방문 완료 여행에 **후기와 별점**을 따로 남길 수 있다 |

## ✨ 주요 기능

### 1. 여행 기록 관리 (CRUD)
- **추가** : 국가, 도시, 날짜, 노래, 메모, 별점, 방문 여부를 입력해 카드로 저장
- **수정** : 카드의 ✎ 버튼으로 기존 값이 채워진 창을 열어 수정
- **삭제** : 상세 팝업에서 삭제 (확인창으로 실수 방지)
- **저장** : 브라우저 `localStorage`에 저장되어 새로고침해도 유지

### 2. 사진 · 음악 자동 연동
- 국가·도시 입력 후 칸을 벗어나면 **입력창 위쪽 사진이 미리보기**로 바뀜
- 노래 검색(돋보기) → 목록에서 선택하면 **곡명과 가수가 자동으로 채워짐**
- 카드의 ▶ 버튼으로 **30초 미리듣기** 재생 (다른 곡을 누르면 이전 곡은 자동 정지)

### 3. 분류와 탐색
- **상태 필터** : 전체 / 방문 완료 / 예정 / 즐겨찾기
- **검색** : 도시·국가 이름으로 실시간 검색
- **정렬** : 최신순 / 오래된순 / 별점순 / 날짜순

### 4. 상세 · 후기
- 카드를 누르면 **상세 팝업**(사진, 별점, 노래, 메모)
- 방문 완료한 여행에는 **후기 작성과 별점**을 따로 저장
- 상세 팝업에서도 즐겨찾기(♥) 가능

### 5. 즐겨찾기 · 홈 대시보드
- 하트를 누른 여행만 모아 보는 **즐겨찾기 화면**
- 홈에서 **전체 / 다녀온 / 예정 / 즐겨찾기 통계**와 최근 여행 앨범, 가장 최근 여행의 대표 화면 표시

### 6. 공유
- 여행 카드를 **이미지(PNG)로 저장·공유** (`html2canvas` + Web Share API)

## 🔌 사용한 API

| API | 용도 | 인증 |
| --- | --- | --- |
| **REST Countries v5** | 국가 정보(이름, 국기) 조회 | Bearer 토큰 |
| **Pixabay** | 국가·도시 검색어로 여행 사진 검색 | API 키 |
| **iTunes Search** | 노래 검색, 곡 정보, 30초 미리듣기 주소 | 불필요 |

모든 API 호출은 `js/api/countries.js`에서 `async / await`와 `try / catch`로 처리하며, 실패하면 `null`을 돌려주어 **앱이 멈추지 않고** 기본 이미지·빈 목록으로 대체됩니다.

## 🗂 데이터 구조

여행 카드 1장은 아래 객체이며, 배열 형태로 `localStorage`의 `travel_memory_cards` 키에 저장됩니다.

```json
{
  "id": 1731200000000,
  "country": "Japan",
  "city": "Osaka",
  "date": "2026-12-24",
  "song": "Lemon",
  "artist": "Kenshi Yonezu",
  "memo": "벚꽃길을 걸으면서 듣고 싶은 노래",
  "rating": 5,
  "visited": false,
  "imageUrl": "https://pixabay.com/...jpg",
  "previewUrl": "https://audio-ssl.itunes.apple.com/...m4a",
  "favorite": false,
  "reviewMemo": "",
  "reviewRating": 0
}
```

| 필드 | 설명 |
| --- | --- |
| `id` | 카드 고유 번호 (`Date.now()`) — 수정·삭제 시 카드를 찾는 기준 |
| `visited` | `true`면 방문 완료, `false`면 예정 |
| `imageUrl` | Pixabay에서 가져온 사진 주소 (실패 시 기본 이미지) |
| `previewUrl` | 30초 미리듣기 주소 |
| `reviewMemo`, `reviewRating` | 방문 완료 후 작성한 후기 |

## ▶ 실행 방법

> 이 프로젝트는 별도 설치(npm)가 필요 없는 **정적 웹앱**입니다.

1. 프로젝트 폴더를 **VS Code**로 엽니다.
2. 확장 프로그램 **Live Server**를 설치합니다.
3. [API 키 설정](#-api-키-설정)을 먼저 완료합니다.
4. `html/index.html`을 열고 우측 하단 **Go Live**를 누릅니다.
5. 브라우저에서 `http://127.0.0.1:5500/Travel_Memory/html/index.html` 로 접속합니다.

### ⚠ 꼭 지켜야 할 점
- **`file://`로 직접 열면 REST Countries가 동작하지 않습니다.** (허용된 출처만 호출 가능) 반드시 Live Server를 사용하세요.
- 데이터는 **브라우저·주소별로 따로 저장**됩니다. `127.0.0.1`과 `localhost`는 서로 다른 저장소이므로, **항상 같은 주소**로 접속하세요.
- 사진은 **영어 도시명**(예: `Tokyo`, `Paris`, `London`)으로 입력할 때 가장 정확하게 검색됩니다.

## 🔑 API 키 설정

실제 키는 저장소에 올리지 않습니다(`.gitignore`에 `config.js` 포함).

1. `config.example.js`를 복사해 같은 폴더에 **`config.js`**로 이름을 바꿉니다.
2. 아래 두 값을 본인의 키로 채웁니다.

```js
const PIXABAY_API_KEY = "여기에_Pixabay_키";
const RESTCOUNTRIES_API_KEY = "여기에_RestCountries_키";
```

| 키 | 발급처 | 비고 |
| --- | --- | --- |
| Pixabay | https://pixabay.com/api/docs/ | 로그인 후 문서 페이지에서 확인 |
| REST Countries | https://restcountries.com/ | 허용 도메인에 `127.0.0.1`, `localhost` 등록 |
| iTunes Search | 키 불필요 | 공개 API |

## 🧩 개발하며 겪은 문제와 해결

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| REST Countries 호출이 `origin 'null'` 오류 | `file://`로 열면 출처가 `null`이라 차단됨 | Live Server(`127.0.0.1`)로 실행 |
| Pixabay 사진이 카드에서 `429` 오류 | 브라우저가 보내는 Referer 때문에 요청 제한 | `<img referrerpolicy="no-referrer">` 지정 |
| 카드 수정 시 새 카드가 하나 더 생김 | 수정 중인 카드를 구분하지 못함 | `editingId` 변수로 수정/추가를 분기 |
| 변수 이름 대소문자 오타(`editingID`)로 수정 안 됨 | JS는 대소문자를 구분 | 이름 통일, 콘솔로 값 확인 |
| 노래 미리듣기가 자동 재생되지 않음 | 브라우저가 자동 재생을 차단 | 사용자 클릭(▶) 이벤트 안에서 재생 |
| 사진 검색 결과가 엉뚱한 나라 | 한글·모호한 검색어 | 국가 + 도시를 합친 영어 검색어 사용 |

## 🚀 아쉬운 점과 개선 계획

- 사진·음악 데이터를 서버에 저장하는 **회원 / 백엔드 연동** (현재는 브라우저 저장소만 사용)

- 수정 시 도시를 바꾸면 **사진도 함께 갱신**
- 지도 연동으로 여행지를 시각화
